# STATIC_A saved Top3 dashboard

WEB-P1 candidate for the dedicated public `static-a-dashboard` repository. Scores are model ranking scores, not calibrated probabilities. Historical research results do not guarantee future returns. Certified Live records: zero.

Static, read-only display of 5538 saved historical selections spanning 2019-01-02 through 2026-10-08. Snapshot observations are as of 2026-10-09; the page does not refresh data automatically. Rank, full saved score, source classification, outcome states and all 20-session detail values are preserved.

Historical replay and retrospective reconstruction are distinguished from certified same-day Live signals. The 21 Phase5R additions are retrospective and Pending, with unverified original capture vintage and unverified official adjusted-price continuation. No entry price or mature return is invented. These historical results do not establish prospective Live performance.

The public payload includes saved adjusted-price paths and 81 rows of stored Base6 values. These are display values, not model weights, raw acquisition captures or feature/scoring code. All 5538 records in `site/assets/dashboard-data.json` are downloadable by visitors; hiding a panel is not an access-control mechanism.

Only `site/` is published. The browser reads static HTML/CSS/JavaScript/JSON, without a backend, database, Python runtime, external CDN, analytics or inference. `site/index.html` is the entry page; all assets use relative URLs for project Pages paths.
