## Audit method and scope

Every record is compared field-by-field against the frozen source. Retained fields stay exactly equal; only the three locator/source-description fields are mapped and the explicitly listed internal fields are excluded. A fail-closed file/field allowlist, full text scan of HTML/JS/CSS/JSON/workflow/docs, recursive decoded JSON-string scan, URL/entity normalization, credential/private-key/email/private-path detection and file checksums are applied. No opaque compressed dataset is included. There is one relative, same-site fetch of saved JSON, no backend polling/inference, analytics or external CDN.

Pattern scanning cannot prove the universal absence of all possible secrets. URL/entity/Unicode escape normalization includes layered-encoding negative controls. The supplied private-review report contains actual safety-test and browser results; the owner must review the intended public corpus and destination before any upload. No completed GitHub run or deployed URL is claimed.
